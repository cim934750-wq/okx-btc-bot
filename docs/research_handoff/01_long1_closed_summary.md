Long1 research round는 closed 상태다.

Long1은 BTC-specific redesign evidence로 유지된다. 그러나 cross-market transfer는 sparse and mixed였고, larger market-basket validation은 Long1을 broad implementation candidate로 upgrade하지 못했다.

## 변경되지 않은 것

- Long1은 여전히 BTC-specific 연구 증거로 남는다.
- Long1 결과는 폐기된 것이 아니라, 일반화된 구현 후보로 승격되지 않은 상태다.

## 열려 있지 않은 것

- Long1 implementation planning은 열려 있지 않다.
- Long1을 현재 단계에서 production strategy, broad-market strategy, implementation candidate로 주장하면 안 된다.

## 금지 사항

- Long1 closed state를 무시하고 구현 계획을 재개하지 않는다.
- Long1 결과를 performance claim으로 확장하지 않는다.
- Long1을 Long2 Option A 이후 변경된 lifecycle 결과와 혼합 해석하지 않는다.

## 결론

Long1은 closed BTC-specific redesign evidence이며, 현재 다음 작업 대상은 아니다.
